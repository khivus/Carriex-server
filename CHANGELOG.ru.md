# История изменений

[English](CHANGELOG.md) | **Русский**

Здесь отражены существенные изменения. Версии следуют Semantic Versioning.

## [Unreleased]

- Русский и английский интерфейсы страницы подключения и локальной панели статистики; переключение языка без изменения JSON, CSV и протокола.
- Русские версии README и документации.

## [0.5.0] - 2026-10-22

### Добавлено

- Постоянные администраторы групп могут публиковать подписанные переименования для текущих участников. Состав и эпоха ключей сохраняются; старые приглашения продолжают работать через подтверждение допуска.
- Необязательные отчёты о прочтении личных сообщений через `POST /messages/<own-id>/read`, отдельно от подтверждений доставки. Получатель с аутентификацией может сообщить о прочтении уже доставленного сообщения; опрос статусов и WebSocket показывают `read`. Отчёты сохраняются после перезапуска, идемпотентны и не раскрывают сообщения карантина или скрытую доставку. На Android отправка отчётов по умолчанию отключена.
- Новая структура бокового меню и настроек Android, необязательное автоматическое принятие запросов, общая проверка личных и групповых запросов, независимые уведомления о приглашениях, выбор темы и акцента.

## [0.4.0] - 2026-10-20

### Добавлено

- Группы под управлением администратора: подписанные изменения состава, принятие приглашений, постоянный администратор, распространение ключей отправителей и рассылка шифротекста. Каждое вступление, удаление или выход повышает эпоху состава; каждый текущий отправитель обновляет ключи перед новой отправкой. См. `GROUPS.md`.
- GET количества сообщений для уведомлений с сохраняемыми отзывными учётными данными, ограниченными собственными счётчиками; индексированные счётчики очереди и ревизии поступления.
- Необязательная сохраняемая почасовая статистика сервера, панель localhost и экспорт JSON/CSV для практических экспериментов (`CARRIEX_STATISTICS=1`).

### Исправлено

- Доступ к событиям группы ограничен периодами участия. Новые участники и приглашённые не могут скачать ранние события, повторное вступление не раскрывает время отсутствия. Подписанные администратором контрольные точки вступления заменяют загрузку всей истории.
- Слишком большие сообщения получают HTTP 413, отдельно от временного исчерпания вместимости.
- Чтение `.env` при запуске с TLS принимает документированный параметр TTL очереди.

## [0.1.0] - 2026-09-07

### Добавлено

- HTTP-отправка сообщений, получение очереди и проверка состояния.
- Доставка по WebSocket и очереди для отключённых получателей в памяти.
- Интеграционные тесты через реальные сокеты.
- Упаковка Python, общая версия пакета/API и документация.
- Docker и Compose с Gunicorn без root.
- GitHub CI, обновления зависимостей и шаблоны для участников разработки.
