# Security

This early-stage server has no authentication, authorization, durable storage,
or built-in TLS. Payload encryption is the client's responsibility. Treat it as
a trusted-network prototype until those controls are implemented.

Use the repository's GitHub Security tab to report vulnerabilities privately
if private reporting is enabled. Otherwise contact a maintainer privately
through their GitHub profile. Do not put exploit details or sensitive payloads
in public issues. Include the affected version and reproduction steps.

Security fixes target the latest release; older versions have no support promise.
