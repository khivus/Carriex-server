# Архивное развёртывание локального TLS

[English](README.md) | **Русский**

Схема с частным CA/Caddy удалена из активной настройки из-за сложности импорта сертификата на каждый телефон. На описанном историческом этапе активным способом был `docker compose up --build -d` с вводом LAN IP и 5000 в приложении. Актуальный вариант с QR-кодом и прямым HTTPS приведён в [основном README](../../README.ru.md).

Файлы сохранены для будущей работы и не загружаются обычным Compose. `HTTPS.md` содержит исторические инструкции, предполагающие размещение файлов развёртывания в корне: перед использованием команд восстановите туда Caddyfile и compose.https.yaml и перенесите SERVER_ADDRESS из архивного .env.example. Соответствующая реализация импорта CA находится в deprecated/local-tls Android-проекта.

При архивировании не менялись работающие контейнеры, сертификаты, тома и закрытые настройки .env.
